# MSQ-8 web

A virtual MSQ-8: an SQ-80-style synthesizer with an 8-track sequencer, songs and the NRV8 drum machine, with a front panel view and a touch view for phones.

Open it: https://jeymadcat-ops.github.io/MSQ-8-web/ (tap the screen once to start the sound).

`msq8-single.html` is the whole page in one file.
